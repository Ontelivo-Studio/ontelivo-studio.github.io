# ontelivo-studio.github.io

Public website of Ontelivo (https://ontelivo.com), served by GitHub Pages from `main`.

Static HTML only; no build step, no analytics, no cookies, no external fonts or scripts. Everything in this repository is public: never commit keys, tokens or internal documents.

- `index.html`: home page.
- `chess-abstract/support/`: support and contact for Chess Abstract.
- Later: `chess-abstract/privacy/` (text owned by compliance, source `docs/PRIVACY.md` in the game repository), `app-ads.txt` (AdMob, A4) and terms of use (L6).
- `CNAME` holds the custom domain; `.nojekyll` turns off Jekyll.
